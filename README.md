# 边缘 AI 智能手环（STM32F103）

基于 STM32F103C8T6 的智能穿戴实训项目。所有数据在终端本地采集、运算、判断并直接执行控制，不依赖手机或云端。

## 功能

| 功能 | 实现 |
|---|---|
| 心率检测 | MAX30102 红外 PPG + 峰值检测算法，静止状态误差约 ±3 bpm |
| 体温 | DS18B20 单总线，0.1℃ 分辨率 |
| 环境温湿度 | DHT11 |
| 六轴姿态 | MPU6050（加速度 + 陀螺仪，硬件 I2C1） |
| 计步 | MPU6050 合加速度 + 阈值/死区峰值检测，含步频与静止判定 |
| 显示 | 1.3 寸 OLED（SSD1306），四页界面，KEY1 翻页 |
| 蓝牙通信 | HC-05/HC-06，手机 App 收发命令、上报数据 |
| 异常报警 | 心率连续 10 秒越界 → 蜂鸣器 + 双 LED 闪烁 + 屏幕提示 |

## 硬件

- 主控：STM32F103C8T6 核心板（64KB Flash / 20KB RAM）
- 板卡：STM32 课程开发板（手环 / 智能插座 / 环境检测三合一）
- 无线：HC-05 蓝牙模块（UART 透传）

## 引脚分配

| 外设 | 引脚 | 接口方式 |
|---|---|---|
| OLED SSD1306 | PB8(SCL) / PB9(SDA) | 软件 I2C，地址 0x78 |
| MPU6050 | PB6(SCL) / PB7(SDA) | 硬件 I2C1，地址 0xD0 |
| MAX30102 | PB10(SCL) / PB11(SDA) | 硬件 I2C2，地址 0xAE |
| MAX30102 INT | PB2 | 未使用（PB2 是 BOOT1，上电为高会进 ISP） |
| DS18B20 | PA8 | 单总线 |
| DHT11 | PB5 | 单总线 |
| 蓝牙模块 | PA2(TX) / PA3(RX) | USART2，9600-8-N-1 |
| CH340G 调试口 | PA9(TX) / PA10(RX) | USART1，115200 |
| LED3 / LED4 | PB3 / PB4 | 低电平点亮 |
| 蜂鸣器 | PA4 | — |
| 继电器 | PA5 | — |
| 按键 KEY1~KEY4 | PB12 / PB13 / PB14 / PB15 | 上拉输入，低电平有效 |

> 蓝牙模块与 ESP8266 共用 M_RXD / M_TXD 网络，板上同一时间只能插一个。

## 实现要点

**MAX30102 数据读取**

硬件 FIFO 只有 32 格，25Hz 采样下 1.3 秒就写满。主循环每 10ms 调用 `MAX30102_Poll()`，按硬件读写指针差值把积压样本搬进 128 组软件环形缓冲，保证读到的永远是新鲜数据。

**心率算法**（`APP/max30102/hr.c`）

```
IR 原始值
  → 一阶低通跟踪直流分量（τ ≈ 1.3s）
  → 相减得到带符号交流分量（不取绝对值，否则每拍出两个峰）
  → 局部极大值检测（高于前后点，且超过峰值一半）
  → 两个峰的间隔 IBI，必须落在 12~50 样本（30~125 bpm）
  → 4 点滑动平均输出心率
```

手指贴上瞬间直流分量从千级爬到十万级，这段过渡期的交流值会异常大，因此加了「直流收敛判断」：连续稳定约 2.4 秒后才开始峰值检测。

**计步算法**（`APP/step/step.c`）

```
MPU6050 三轴加速度（mg）
  → mag = sqrt(ax² + ay² + az²)          与佩戴方向无关，只看运动冲击
  → 5 点滑动平均（50Hz，即 100ms 窗）      滤掉手抖/路面颠簸的高频毛刺
  → 上升沿穿越阈值 TH = 1200mg            与静止基线 1000mg 拉开的距离即灵敏度
  → 回落到 1050mg 以下才重新武装           施密特迟滞，防止在阈值附近抖动重复计数
  → 与上一次峰值间隔 ≥ 300ms              死区时间，同一步的二次抖动被丢弃
  → 两个条件同时满足，步数 +1
```

参数取值：采样率 50Hz（20ms）保证每个步态周期有 15~25 个样本；窗口 100ms 对 1~2Hz 的步态波峰只衰减约 6%；300ms 死区对应人体极限步频 200 步/分钟，正常步行 90~130、跑步 160~180 都落在死区之外。步频由最近 4 次步间隔平均后换算（60000 / 平均间隔），3 秒无新步判定为静止、步频输出 0。

边界处理：合加速度超出 300~6000mg（I2C 全 0、自由落体、剧烈撞击）的样本直接丢弃并计入错误计数；连续 25 个异常样本（0.5s）判定传感器故障，复位检测器并在 P4 页显示 `I2C ERR`，恢复后自动重新计步，已计步数不丢。采样时间基准用 TIM2 自由计数器（10kHz，增量累加），不靠主循环次数估算，也不开定时器中断，因此 OLED 刷屏、DHT11/DS18B20 位操作造成的循环抖动不会影响 300ms 死区。

**报警逻辑**

心率低于 50 或高于 110，连续 5 次采样周期（约 10 秒）才确认，避免单次测量抖动误报。报警时蜂鸣器与 LED 间歇闪烁，优先级高于手动开关状态；心率恢复后自动解除。

## 已知限制

- **血氧未实现**：实测红光与红外通道的直流分量几乎相等，R 值区分度不足，且没有标准血氧仪做标定，只做趋势没有意义。
- **蓝牙 AT 模式不可用**：板上模块 EN 脚悬空，无法通过 GPIO 拉高进入 AT 模式，只能使用出厂默认名称与波特率。
- **OLED 为软件 I2C**：刷屏约 40ms，若后续增加刷新频率需改硬件 I2C 或 DMA。
